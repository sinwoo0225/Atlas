---

**갱신 규칙**

- 새 작업 착수 → 진행 중에 항목 추가 (시작 날짜 + 다음 단계 + 미결 결정사항 명시).
- 단계 전환·세션 종료 → 진행 중 항목의 "다음" 메모 최신화.
- 작업 완료 → 항목 제거 + `docs/개발로그.md` 오늘 날짜 섹션에 append.
- 백로그 → 진행 중 promote 시 위 규칙 동일.
