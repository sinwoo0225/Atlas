# v1.35.0

*2026-07-15 · 이전: v1.34.0*

## 한국어

### 새로운 기능

- 📌 **위젯 도킹 (작업표시줄처럼 고정)** — 위젯을 화면 가장자리에 붙여 데스크톱 공간을 예약합니다. 다른 창을 최대화해도 위젯을 덮지 않습니다. 모니터(주/보조)·부착 위치(좌/우)·너비를 고를 수 있고, Atlas 를 닫으면 예약이 자동으로 해제됩니다.
- 👤 **위젯 '내 작업 / 임박·지연'** — 위젯이 이제 **내게 할당된** 미완 업무만 모아 보여줍니다(일정·이슈·개인 TODO 통합). 마감이 지났거나 임박한 것은 위쪽 '임박·지연'으로 따로 구분됩니다. (이전에는 담당자와 무관하게 전체 작업이 섞여 보였습니다.)
- 🗂️ **WBS/일정 항목을 '그룹'으로** — 상위 항목을 순수 '그룹'으로 지정할 수 있습니다. 그룹은 완료율·번업·지연 등 진행 지표에서 빠지고, 자식이 모두 끝나면 완료로 표시됩니다. 그룹 노릇을 하던 상위 항목이 통계에서 '미완료 작업'으로 잡히던 문제를 해소합니다(자식을 처음 추가하면 자동으로 그룹이 되며, '작업으로 유지'로 되돌릴 수 있습니다).
- 📅 **업무일지에서 '주간 통합 보기'** — 업무일지 화면에서 버튼 하나로, 통합 모니터링의 '이번 주' 주간 업무일지(전 프로젝트·회고 다이제스트·다음 주 계획·미해결 이슈)를 모달로 바로 봅니다.
- 📝 **릴리즈 노트 보기** — 새 버전이 나오면 알림에서 릴리즈 노트를 바로 열 수 있고(종 알림 패널에도 남습니다), **설정 › 정보 › '이 버전의 새로운 기능'**에서 지금 쓰는 버전의 변경 사항을 **오프라인에서도** 볼 수 있습니다.

### 비고

## English

### New

- 📌 **Widget docking (pin like the taskbar)** — Dock the widget to a screen edge so it reserves desktop space; maximized windows no longer cover it. Choose the monitor (primary/secondary), side (left/right), and width. The reservation is released automatically when you close Atlas.
- 👤 **Widget "My work / Due & overdue"** — The widget now shows only the open work **assigned to you** (Schedule + Issues + personal TODOs, combined), with overdue and due-soon items grouped at the top. (Previously it mixed in everyone's work regardless of assignee.)
- 🗂️ **Mark a WBS/Schedule item as a "Group"** — Designate a parent item as a pure group. Groups drop out of progress metrics (completion %, burn-up, overdue) and show as done once all children are done — fixing parents that used to count as "incomplete work." (Adding the first child auto-converts it to a group; you can undo with "Keep as task.")
- 📅 **"Weekly overview" from the work log** — One button on the work-log screen opens this week's integrated weekly work log (all projects, retrospective digest, next-week plan, open issues) in a modal.
- 📝 **View release notes** — When a new version is available you can open its release notes right from the notification (and it stays in the bell panel). And under **Settings › About › "What's new in this version"** you can read the current version's changes **even offline**.

### Notes

- All data stays on your PC; nothing is sent externally.
