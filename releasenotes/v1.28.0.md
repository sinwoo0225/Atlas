# v1.28.0

*2026-06-25 · 이전: v1.27.0*

## 한국어

### 새로운 기능

- 🏷️ **이슈 분류(Category) + 사용자 정의 컬럼** — 이슈 목록 제목 왼쪽에 자유 입력 **분류** 칸이 생겼습니다. 한 번 쓴 분류는 다음부터 **자동완성**으로 떠서 빠르게 고를 수 있고, 새 값도 그대로 입력됩니다. 또한 **나만의 컬럼**(이름 + 유형: 텍스트·날짜·숫자)을 직접 추가해 이슈마다 값을 적을 수 있습니다. 기존 컬럼은 그대로 고정됩니다.
- 👥 **회의록 참석자 입력 간소화** — 소속별로 인원을 한 명씩 줄 추가하던 방식 대신, **콤마·엔터로 구분해 한 번에 입력**합니다(WBS 담당자 입력과 동일). 이름을 치면 **내 자원(리소스)에서 자동완성**(부서 표시)으로 골라집니다. 소속 구분은 그대로 유지됩니다.

### 비고

- 분류·커스텀 컬럼 값은 종전과 동일하게 내 PC(로컬 DB)에 저장되며, 외부 자동화(atlas-cli/atlas-mcp)에서도 읽고 쓸 수 있습니다.
- 자동완성 드롭다운이 표·카드 영역에 잘리지 않고 위로 떠서 표시되도록 개선했습니다(이슈 분류 칸, 회의록 참석자, WBS/일정 담당자 공통).

## English

### New

- 🏷️ **Issue category + custom columns** — A free-text **Category** field now sits to the left of the issue title. Categories you've used before show up as **autocomplete** suggestions for quick reuse, and new values are accepted as-is. You can also add **your own columns** (name + type: text / date / number) and fill in a value per issue. Existing columns stay fixed.
- 👥 **Simpler meeting attendee entry** — Instead of adding people one row at a time per organization, type attendees separated by **comma or Enter** (same as the WBS assignee field). As you type, names **autocomplete from your resources** (with department shown). Organization grouping is preserved.

### Notes

- Category and custom-column values stay on your PC (local DB) as before, and are readable/writable from external automation (atlas-cli / atlas-mcp).
- Autocomplete dropdowns now float above table/card areas instead of being clipped (shared across the issue category field, meeting attendees, and the WBS/schedule assignee field).
