# v1.25.0

*2026-06-16 · 이전: v1.24.0*

## 한국어

### 새로운 기능
- ✅ **내 업무 (통합 할 일)** — 여러 프로젝트의 미완 WBS 작업·미해결 이슈와 프로젝트에 속하지 않는 개인 할 일(TODO)을 한 화면에 모아 봅니다. 마감일 순 정렬, 반복 할 일(매일·매주·매월·매년), 한 줄 완료 처리를 지원합니다.
- 🔁 **프로젝트 회고** — 완료한 프로젝트들을 골라 비교 분석합니다. 번업(S곡선) 추이, 일정 지연율, 이슈 밀도·평균 해결 시간 등을 한눈에 봅니다.
- 🗓️ **계획 vs 실적 일자 분리** — WBS 작업·이슈·프로젝트에 실적 완료일을 추가했습니다. 완료/해결 처리 시 자동으로 기록되며(수동 보정 가능), 기존 일정 일자는 '계획'으로 유지됩니다.
- 🔒 **개인 할 일은 내 것만** — 원격 서버를 함께 쓰는 환경에서도 개인 할 일은 항상 작성자 본인에게 귀속되어, '전체' 보기에서도 다른 사람의 개인 할 일은 보이지 않습니다. (공유 자료인 WBS·이슈는 종전처럼 전체를 볼 수 있습니다.)
- 🧭 **사이드바 개편** — 전역 메뉴를 주요·분석·관리 세 묶음으로 정리하고, 프로젝트 작업 중에는 왼쪽을 아이콘 레일로 줄여 세로 공간을 절약합니다. 레일의 펼침 버튼을 누르면 통합 메뉴가 위로 펼쳐집니다(Esc·바깥 클릭으로 닫힘).

### 비고
- 기존 데이터는 시작 시 자동으로 마이그레이션됩니다. 모든 데이터는 종전과 동일하게 로컬(SQLite + 파일 폴더)에 저장됩니다. 계정·원격 서버 없음(원격 서버는 사내 LAN 선택 기능).

## English

### New
- ✅ **My work (unified to-dos)** — See open WBS tasks and unresolved issues across all your projects together with standalone personal to-dos that don't belong to any project, all on one screen. Sorted by due date, with recurring to-dos (daily/weekly/monthly/yearly) and one-click completion.
- 🔁 **Project retrospective** — Pick completed projects and compare them: burn-up (S-curve) trends, schedule slippage, issue density, average resolution time, and more at a glance.
- 🗓️ **Planned vs. actual dates** — WBS tasks, issues, and projects now track an actual completion date, stamped automatically on completion/resolution (and adjustable). Existing schedule dates remain as the "planned" dates.
- 🔒 **Personal to-dos stay yours** — Even when sharing a remote server, personal to-dos are always attributed to their author, so other people's personal to-dos never appear — not even in the "All" view. (Shared WBS and issues remain viewable across everyone as before.)
- 🧭 **Redesigned sidebar** — Global menus are grouped into Main, Insights, and Manage; while you work inside a project the left side shrinks to an icon rail to save vertical space. Click the expand handle to slide the global menu open (close with Esc or by clicking outside).

### Notes
- Existing data migrates automatically on startup. All data stays local (SQLite + file folders) as before. No account, no remote server (the remote server is an optional LAN feature).
