# Release Notes

사용자 관점의 버전별 변경 사항. **1 버전 = 1 파일** (`vX.Y.Z.md`), 최신순.

이 폴더는 개발 내부 기록(`docs/개발로그/`, 로컬 전용)과 달리 **사용자에게 보이는 변경**만 담습니다. 그대로 재사용:
- Microsoft Store 제출의 "이 버전의 새로운 기능 / What's new"
- GitHub Release 본문
- 앱 내 안내(필요 시)

## 작성 규칙

- 새 버전을 낼 때마다 `releasenotes/vX.Y.Z.md` 를 추가하고 아래 인덱스 맨 위에 한 줄 링크.
- 한국어·영어 병기(앱이 양 언어 지원).
- 기능/사용자 영향 위주. 내부 리팩터링·빌드 변경은 생략하거나 한 줄로.
- 과대광고·미구현 주장 금지(실제 동작과 일치).
