# v1.34.0

*2026-07-10 · 이전: v1.33.0*

## 한국어

### 새로운 기능

- 🏷️ **프로젝트 '구분' 커스텀 등록** — 고정 항목(과제·내부·사업) 대신 원하는 구분을 자유롭게 입력·등록할 수 있습니다. 프로젝트 폼의 구분 필드가 자동완성 콤보박스로 바뀌어, 기존에 쓰던 값은 제안으로 뜨고 새 값은 바로 입력됩니다.
- ⏸️ **일정/WBS '중단' 상태 추가** — 멈춰서 더 진행하지 않을 작업을 '중단'으로 표시합니다. 중단 작업은 완료율·번업·지연 등 진행 지표에서 빠지지만(멈춘 일이 진척률을 깎지 않음), 칸반·목록·간트에는 그대로 보입니다.
- 🌲 **일정/WBS 트리 접힘 상태 유지** — 트리를 접어둔 상태가 새로고침하거나 프로젝트를 옮겨도 프로젝트별로 기억됩니다.

### 자동화 (Claude Code)

- 🤖 **회의록 요약 스킬 `/atlas-meeting-summary`** — 저장된 회의록을 Claude Code 세션에서 읽어 요약·결정 사항·액션 아이템을 자동으로 정리해 채웁니다(`atlas-cli skill install` 로 함께 설치).

### 비고

- 모든 데이터는 내 PC에만 저장되며 외부로 전송되지 않습니다.

## English

### New

- 🏷️ **Custom project "category"** — Instead of a fixed list, enter and register any category you like. The category field is now an autocomplete combobox that suggests values you've used and accepts new ones.
- ⏸️ **New "Suspended" status for Schedule/WBS** — Mark work that has stopped and won't continue as Suspended. Suspended tasks drop out of progress metrics (completion %, burn-up, overdue) — so parked work no longer drags your progress down — while still showing on the board, list, and Gantt.
- 🌲 **Schedule/WBS tree collapse state is remembered** — Collapsed/expanded state now persists per project across reloads and project switches.

### Automation (Claude Code)

- 🤖 **Meeting-summary skill `/atlas-meeting-summary`** — Reads a stored meeting record in a Claude Code session and auto-fills its summary, decisions, and action items (installed via `atlas-cli skill install`).

### Notes

- All data stays on your PC; nothing is sent externally.
