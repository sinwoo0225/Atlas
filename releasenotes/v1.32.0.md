# v1.32.0

*2026-07-01 · 이전: v1.31.0*

## 한국어

### 새로운 기능

- 🧭 **설정 마법사(최초 실행 안내)** — 앱을 처음 실행하면 **언어 · 본인 등록 · 통합 모니터링 '작업' 탭 기본 보기 · 테마 · 마크다운 뷰어 · 알림**을 단계별로 한 번에 설정합니다. 기존 사용자에게는 한 번만 안내하며, **설정 화면 상단의 '설정 마법사' 버튼**으로 언제든 다시 실행할 수 있습니다.
- ➕ **프로젝트 드롭다운에서 새 프로젝트 바로 생성** — 사이드바 위쪽 프로젝트 선택 드롭다운 아래의 **'새 프로젝트'** 로 목록 화면으로 가지 않고 바로 만들 수 있습니다.
- 🔽 **일정/WBS 다중 접기·펼치기** — 표·간트 위쪽 버튼으로 **모두 펼치기 / 2·3레벨까지 / 모두 접기**를 한 번에 적용합니다(표·간트가 같은 접힘 상태 공유).
- ✏️ **WBS 서브태스크 제목 인라인 편집** — 작업 안 체크리스트 항목의 제목을 클릭해 바로 수정합니다.
- 🟢 **WBS 생성 시 상태에 따라 업무일지 자동 기록** — 새 작업을 **대기 · 진행 · 완료** 상태로 만들면(예정이 아니면), 상태 변경과 동일하게 그날 업무일지에 자동으로 남습니다.
- 🖱️ **통합 메뉴 펼치기 방식 선택(클릭/마우스오버)** — 설정에서 통합(전역) 메뉴를 **버튼 클릭** 대신 **마우스 오버**로 펼치도록 바꿀 수 있습니다. 펼친 메뉴 안에서도 **알림 종**을 바로 열 수 있습니다.
- 📖 **업무일지 상단 미리보기 영역 확대** — 요일별 미리보기 카드 높이를 넓혀 더 많은 내용을 봅니다.

### 개선

- 설정의 '기본 작성자 이름 (나)'를 실제 쓰임에 맞게 **'본인 등록'**으로 명칭을 정리했습니다.
- Microsoft Store 버전에서는 패키지 특성상 **작업표시줄 아이콘 변경이 반영되지 않아**, 해당 설정에 안내를 표시합니다(아이콘 커스터마이즈는 설치본을 이용).

### 비고

- 모든 데이터는 내 PC에만 저장되며 외부로 전송되지 않습니다.

## English

### New

- 🧭 **Setup wizard (first-run onboarding)** — On first launch, set up **language · your identity · the monitoring 'Tasks' tab default view · theme · markdown viewer · notifications** step by step. Existing users are prompted once, and you can re-run it anytime from the **'Setup wizard' button at the top of Settings**.
- ➕ **Create a new project straight from the project dropdown** — Use **'New project'** at the bottom of the project selector to create one without leaving your current screen.
- 🔽 **Collapse / expand the Schedule/WBS tree in bulk** — Buttons above the table/Gantt apply **Expand all / 2·3 levels / Collapse all** at once (table and Gantt share the same collapsed state).
- ✏️ **Inline-edit WBS subtask titles** — Click a checklist item's title inside a task to edit it in place.
- 🟢 **Auto work-log entry when creating a WBS task with a status** — Creating a task as **Waiting · In progress · Done** (anything but Planned) records it in that day's work log, just like a status change.
- 🖱️ **Choose how the integrated menu expands (click / hover)** — In Settings, open the integrated (global) menu on **mouse hover** instead of a button click. You can open the **notification bell** from inside the expanded menu too.
- 📖 **Taller work-log preview** — The day preview cards are taller so you see more at a glance.

### Improvements

- Renamed Settings' 'Default author name (me)' to **'My identity'** to match how it's actually used.
- On the Microsoft Store build, the **taskbar icon can't be changed** due to packaging, so the setting now explains this (use the installer build to customize the icon).

### Notes

- All data stays on your PC; nothing is sent externally.
