# v1.33.0

*2026-07-01 · 이전: v1.32.0*

## 한국어

### 새로운 기능

- 📊 **마크다운 뷰어 대폭 개선** — 회의록·업무일지·이슈·변경 이력·WBS 메모·업무 정보·프로젝트 맵 등 앱 전반의 마크다운에서 이제 다음이 표시됩니다.
  - **표**, 체크리스트(`- [ ]`), 취소선, 자동 링크
  - **`<br/>` 등 안전한 HTML 태그** (`<script>`·인라인 스타일 등 위험 요소는 자동 제거)
  - **Enter 한 번으로 줄바꿈** (이전에는 한 문단으로 합쳐졌습니다)
  - **코드 블록 구문 강조** (오프라인, 테마에 맞춰 색 자동 조정)
- 🔗 **마크다운 내 외부 링크는 시스템 브라우저로** — 본문의 링크를 클릭하면 앱을 벗어나지 않고 기본 브라우저에서 열립니다.

### 비고

- 새로 추가된 렌더링 라이브러리는 모두 permissive 라이선스(MIT/BSD-3-Clause)로, 앱 배포에 제약이 없습니다.
- 모든 데이터는 내 PC에만 저장되며 외부로 전송되지 않습니다.

## English

### New

- 📊 **Much better Markdown rendering** — Markdown across the app (meeting notes, work log, issues, change logs, WBS notes, work info, project map, …) now renders:
  - **Tables**, checklists (`- [ ]`), strikethrough, and autolinks
  - **Safe HTML tags such as `<br/>`** (dangerous bits like `<script>` and inline styles are stripped automatically)
  - **A single newline as a line break** (previously merged into one paragraph)
  - **Code-block syntax highlighting** (offline, colors adapt to your theme)
- 🔗 **External links in Markdown open in your browser** — Clicking a link in the body opens it in your default browser instead of navigating away inside the app.

### Notes

- The newly added rendering libraries are all permissively licensed (MIT / BSD-3-Clause), with no distribution restrictions.
- All data stays on your PC; nothing is sent externally.
