# v1.30.0

*2026-06-28 · 이전: v1.29.0*

## 한국어

### 새로운 기능

- 🔔 **알림** — 마감이 임박한 일정·이슈와 매일의 업무 정리를 **메인 화면 우측 하단 토스트**로 알려줍니다.
  - 사이드바 검색 아이콘 위에 **종 모양 아이콘**이 생기고, 미확인 알림이 있으면 빨간 점이 표시됩니다. 클릭하면 **최신순 알림 목록**을 볼 수 있습니다.
  - **마감 임박 일정/이슈** — 내가 담당인 작업만 볼지 전체를 볼지 고르고, 며칠 전부터 알릴지·마감 초과 항목 포함 여부를 정합니다. 같은 항목은 임박→당일→초과 단계마다 한 번씩만 알립니다.
  - **일일 업무 정리** — 매일 지정한 시각에 오늘 마감·지연·진행 중 건수와 함께 하루를 정리하라고 안내합니다.
  - 설정 → **알림 탭**에서 항목별 켜기/끄기·시각·확인 주기를 조정하고, 테스트 알림으로 미리 확인할 수 있습니다.
  - 앱 창을 **최소화해 둬도** 알림이 표시됩니다(Windows 알림 센터에는 기록되지 않습니다). 알림 메시지는 한국어·영어와 테마가 그대로 적용됩니다.

### 비고

- 알림은 내 PC에서만 동작하며 외부로 전송되지 않습니다.
- 향후 알림 종류를 쉽게 추가할 수 있도록 내부 구조를 설계했습니다.

## English

### New

- 🔔 **Notifications** — Bottom-right toasts on the main screen for **approaching deadlines** (schedules/issues) and a **daily work summary**.
  - A **bell icon** appears above the sidebar search, with a red dot when there are unread items. Click it for a **reverse-chronological list** of notifications.
  - **Approaching deadlines** — choose "my tasks only" or all tasks, set how many days ahead to alert, and whether to include overdue items. Each item alerts once per stage (soon → due today → overdue).
  - **Daily work summary** — at a time you set, a daily nudge with counts of items due today, overdue, and in progress.
  - Configure per-type enable/time/check-interval in Settings → **Notifications**, with a test button to preview.
  - Toasts appear **even when the app is minimized** (without cluttering the Windows notification center). Messages are fully localized (Korean/English) and themed.

### Notes

- Notifications run entirely on your PC; nothing is sent externally.
- The internals are structured so new notification types can be added easily.
