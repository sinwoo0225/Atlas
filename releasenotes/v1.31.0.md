# v1.31.0

*2026-06-30 · 이전: v1.30.0*

## 한국어

### 새로운 기능

- 📋 **일정/WBS 칸반 뷰** — 프로젝트의 일정/WBS 화면에 **칸반** 보기가 추가됩니다(표·간트와 나란히 전환).
  - **상태 기준**(예정·대기·진행·완료)과 **담당자 기준** 두 가지로 그룹화하고, 상태 보드에서는 **카드를 드래그**해 작업 상태를 바꿉니다(상태 변경 시 업무일지 자동 기록도 그대로 동작).
  - 말단 작업만 카드로 표시하며, 이슈는 포함하지 않습니다.
- ⏸️ **WBS '대기' 상태 추가** — 일정/WBS 상태에 **대기**가 생겨 **예정·대기·진행·완료** 순으로 쓸 수 있습니다.
- ☑️ **WBS 여러 작업 한 번에 부모 이동** — '선택' 모드로 여러 작업을 고르면 **함께 옮겨질 본인과 하위 작업이 강조**되고, 한 번에 새 부모로 이동합니다.
- 📝 **업무 일지 '진행 항목 자동 작성'** — '한 일'의 버튼 한 번으로 현재 프로젝트의 **진행/대기 상태 작업·진행 이슈**를 그날 일지에 `[진행]`·`[대기]`로 자동 추가합니다(기존 줄은 현재 상태로 갱신).
- 🙋 **업무일지 작성 범위 설정(자신만/전체)** — 설정에서 **자신만**을 고르면 내가 담당인 작업/이슈의 상태 변경·자동 작성만 일지에 기록됩니다.
- 🗓️ **주간 업무일지 통합 방식 설정(요일별/주간 최종 상태)** — 통합 모니터링 '일지' 탭을 요일별(기존)뿐 아니라 **요일 구분 없이 작업별 최종 상태**로 합쳐 볼 수 있습니다.
- ⭐ **메뉴 즐겨찾기** — 자주 쓰는 **프로젝트 메뉴·통합 메뉴는 물론, 통합 모니터링의 특정 탭(예: 칸반·일지)**까지 사이드바 상단에 고정해 한 번에 이동합니다(메뉴에 마우스를 올리면 별 표시).

### 개선

- 일정/WBS **필터**가 선택한 대상을 강조하는 대신 **비대상을 흐리게** 처리해, 저장한 필터 뷰에서도 색 잔상 없이 깔끔합니다.
- **업무 일지** 화면이 세로로 가득 차도록 정리하고, '한 일'·'이슈' 입력 높이를 맞췄으며, **편집↔미리보기 전환 시 높이가 흔들리지 않습니다**.
- 칸반 컬럼이 작업 수만큼만 차지하도록 여백을 줄였습니다.

### 비고

- 모든 데이터는 내 PC에만 저장되며 외부로 전송되지 않습니다.

## English

### New

- 📋 **Schedule/WBS Kanban view** — A **Kanban** view is added to a project's Schedule/WBS screen (switch alongside Table/Gantt).
  - Group by **status** (Planned · Waiting · In progress · Done) or by **assignee**; on the status board, **drag cards** to change a task's status (auto work-log entry on status change still applies).
  - Only leaf tasks appear as cards; issues are not included.
- ⏸️ **New WBS 'Waiting' status** — Schedule/WBS now has a **Waiting** status, ordered **Planned · Waiting · In progress · Done**.
- ☑️ **Move multiple WBS tasks to a new parent at once** — In 'Select' mode, picking tasks **highlights each task and its descendants that will move together**, then moves them under a new parent in one action.
- 📝 **Work log 'Auto-fill in-progress'** — One button on 'Done' adds the project's **in-progress/waiting tasks and in-progress issues** to that day's log as `[진행]`/`[대기]` (existing lines are updated to the current status).
- 🙋 **Work-log scope setting (Mine only / All)** — Choose **Mine only** to log status changes and auto-fill for tasks/issues assigned to you only.
- 🗓️ **Weekly work-log aggregation setting (By day / Weekly final state)** — The integrated monitoring 'Logs' tab can merge all days into a **final state per task** instead of day-by-day.
- ⭐ **Menu favorites** — Pin frequently used **project menus, integrated menus, and even a specific monitoring tab (e.g. Kanban/Logs)** to the top of the sidebar for one-click navigation (hover a menu to star it).

### Improvements

- The Schedule/WBS **filter** now **dims non-matches** instead of highlighting matches, so saved filter views stay clean with no lingering color.
- The **Work log** screen fills the height, the 'Done'/'Issues' editors are aligned, and **the height no longer jumps when toggling edit ↔ preview**.
- Kanban columns are compact, taking only as much space as their cards.

### Notes

- All data stays on your PC; nothing is sent externally.
