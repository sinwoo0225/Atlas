# v1.29.0

*2026-06-27 · 이전: v1.28.0*

## 한국어

### 새로운 기능

- 📋 **업무일지 계층형 자동 기록 + 시작/완료 전환** — 작업을 진행·완료로 바꾸면 '한 일'에 작업 계층(부모–자식)이 들여쓰기 그대로 자동 기록됩니다. 시작( `[시작]` )과 완료( `[완료]` )가 한 줄에서 전환되고, 같은 부모의 여러 작업이 한데 모입니다. WBS 작업·이슈 모두 적용됩니다.
- 🔢 **이슈 프로젝트별 번호** — 이슈마다 프로젝트별 일련번호( #1, #2 … )가 붙어 참조·검색이 쉬워집니다. 기존 이슈에도 생성 순으로 자동 채워집니다.
- 🗂️ **WBS 서브태스크 · 실적 일자 · 시작 지연 인사이트** — WBS 작업에 가벼운 체크리스트(서브태스크)를 달 수 있고, 실제 시작/완료 일자를 계획과 별도로 기록합니다. 시작 예정일이 지났는데 아직 착수하지 않은 작업을 인사이트로 알려줍니다.
- ⭐ **프로젝트 목록 즐겨찾기** — 자주 보는 프로젝트를 즐겨찾기로 상단에 고정합니다.
- 🧩 **입력 폼 재배치** — 일정/WBS 작업 폼을 3열(기본·일정 / 관계 / 상세)로, 업무 정보 폼을 2열(공통 / 타입별)로 넓게 재배치해 한눈에 입력합니다. 부모 작업은 떠 있는 드롭다운으로 선택합니다.
- 📊 **통합 모니터링 개요 재배치 + WBS 템플릿 미리보기** — 모니터링 개요 상단을 포트폴리오 + 주의 2열로, 하단 9개 카드를 주제별 3×3(요약 → 진척 → 리스크)으로 재배치했습니다. WBS 템플릿을 적용할 때 '등록될 작업명' 계층 트리를 미리 보여줍니다.

### 비고

- 변경 이력·이슈 목록을 점진 렌더링 + 검색 디바운스로 가볍게 했습니다 — 데이터가 많아도 스크롤·검색이 부드럽습니다.
- 업무일지의 '계획' 칸은 통합 모니터링 '일지' 주간 화면의 "다음 주 계획" 섹션으로 옮겼습니다(기존 계획 데이터는 보존). 프로젝트 내부 메뉴 순서도 작업 흐름에 맞게 조정했습니다(회의록을 변경 이력 앞으로).
- 일지 자동 기록 줄( `[시작]`/`[완료]`/`(작업)`/`(이슈)` )은 내 PC(로컬 DB)에 저장되는 내용으로, 외부 자동화(atlas-cli / atlas-mcp)에서도 그대로 읽고 쓸 수 있습니다.

## English

### New

- 📋 **Hierarchical work-log auto entries + start/done toggle** — When you move a task to In progress or Done, your work log's "Done" records the task's hierarchy (parent–child) with indentation. Start ( `[시작]` ) and done ( `[완료]` ) swap in place on the same line, and sibling tasks group under their parent. Applies to both WBS tasks and issues.
- 🔢 **Per-project issue numbers** — Each issue gets a per-project sequence number ( #1, #2 … ) for easier reference and search. Existing issues are backfilled in creation order.
- 🗂️ **WBS subtasks · actual dates · start-delay insight** — Add a lightweight checklist (subtasks) to a WBS task, record actual start/completion dates separately from the plan, and get an insight for tasks whose planned start has passed but haven't begun.
- ⭐ **Project list favorites** — Pin frequently used projects to the top via favorites.
- 🧩 **Form layout redesign** — The WBS task form is now a 3-column layout (Basics & schedule / Relations / Details) and the Work-info form a 2-column layout (Common / type-specific), using the width for at-a-glance entry. Parent task is picked from a floating dropdown.
- 📊 **Monitoring overview regrouped + WBS template preview** — The monitoring overview now shows Portfolio + Attention in two columns up top and the nine cards in a themed 3×3 grid (summary → progress → risk). Applying a WBS template now previews the hierarchy of task names that will be created.

### Notes

- Change-log and issue lists now use incremental rendering + search debounce, so scrolling and searching stay smooth even with lots of data.
- The work-log "Plan" field moved to a "Next-week plan" section in the monitoring weekly view (existing plan data is preserved). The in-project menu order was also adjusted to match the workflow (Meetings before Change log).
- Auto-generated log lines ( `[시작]`/`[완료]`/`(작업)`/`(이슈)` ) are content stored on your PC (local DB) and remain readable/writable from external automation (atlas-cli / atlas-mcp).
