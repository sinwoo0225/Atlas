# v1.23.0

*2026-06-03 · 이전: v1.22.0*

## 한국어

### 새로운 기능
- 🌐 **한국어·영어 UI 전환** — 설정 > 동작 > 언어에서 UI 언어를 한국어/영어로 즉시 전환합니다(기본 한국어, 재시작 불필요). 대시보드·WBS·이슈·회의록·변경 이력·개발 정보·프로젝트 맵·통합 모니터링·업무 일지·리소스·위젯·설정까지 전 화면이 번역됩니다.
- 🪟 **Microsoft Store 출시** — Store(MSIX)로도 설치할 수 있습니다. Store로 설치한 경우 업데이트는 Store가 관리하므로 앱 내 수동 업데이트 UI는 표시되지 않습니다. (포터블 zip·설치형 exe는 종전대로 앱 내 업데이트 동작.)
- 📄 **오픈소스 라이선스 고지** — 설정 > 시스템 > 오픈소스 라이선스에서 앱이 사용하는 오픈소스 구성요소와 라이선스 전문을 볼 수 있습니다.

### 변경
- 🔒 라이선스를 독점(Proprietary)으로 전환했습니다. **기능·데이터·사용 방식은 동일**하며 사용자에게 미치는 영향은 없습니다.

### 비고
- 모든 데이터는 종전과 동일하게 로컬(SQLite + 파일 폴더)에 저장됩니다. 계정·원격 서버 없음.

## English

### New
- 🌐 **Korean / English UI toggle** — Switch the UI language from Settings > Behavior > Language (Korean by default, no restart). Every screen is translated: dashboard, WBS, issues, meetings, change log, dev info, project map, monitoring, worklog, resources, widget, and settings.
- 🪟 **Available on the Microsoft Store** — You can now install Atlas from the Store (MSIX). For Store installs, updates are managed by the Store, so the in-app manual update UI is hidden. (Portable zip / installer exe keep the in-app updater as before.)
- 📄 **Open-source license notices** — See Settings > System > Open-source licenses for the bundled open-source components and their full license texts.

### Changed
- 🔒 The license is now proprietary. **Features, data, and behavior are unchanged** — no user-facing impact.

### Notes
- All data stays local (SQLite + file folders) as before. No account, no remote server.
