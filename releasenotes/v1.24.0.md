# v1.24.0

*2026-06-07 · 이전: v1.23.0*

## 한국어

### 새로운 기능
- 📁 **업무 정보 + 깃 저장소** — 기존 '개발 정보'를 '업무 정보'로 넓혔습니다. 프로젝트의 깃 저장소를 업무 정보의 한 종류로 등록·연결할 수 있고(프로젝트당 여러 저장소), 선택한 저장소의 커밋 그래프를 봅니다.
- 🔗 **WBS ↔ 업무 정보 연결** — WBS 작업 상세의 '관련 정보'에서 관련 문서·링크·저장소를 연결해 한 작업의 맥락을 한곳에 모읍니다.
- 🗂️ **회의록 내부/외부 구분 + 1:3 보기** — 회의를 내부/외부로 분류하고, 목록↔상세 1:3 마스터-디테일로 빠르게 탐색합니다(키보드 ↑/↓ 이동). 업무 일지는 하위가 없는 WBS 리프 작업에만 기록되도록 정리했습니다.
- ✨ **시각 위계·일관성 개선** — 사이드바·필터 바·마크다운 본문 폭을 화면 전반에서 통일해 가독성을 높였습니다.
- 🤖 **외부 자동화·AI 연동 강화** — `atlas-cli`(셸)·MCP 로 작업·이슈·업무 정보를 타깃 필터로 조회하고 상태를 갱신할 수 있습니다. `atlas-cli skill install` 한 번이면 Claude Code 에 Atlas 스킬이 설치돼 자연어로 데이터를 다룰 수 있습니다.

### 변경
- 🏷️ 화면 명칭 '개발 정보'가 '업무 정보'로 바뀌었습니다(데이터·사용 방식 동일).

### 비고
- 기존 데이터는 시작 시 자동으로 마이그레이션됩니다. 모든 데이터는 종전과 동일하게 로컬(SQLite + 파일 폴더)에 저장됩니다. 계정·원격 서버 없음.

## English

### New
- 📁 **Work info + Git repositories** — "Dev info" is now the broader "Work info". A project's Git repositories can be registered and linked as a type of work info (multiple repos per project), with a commit graph for the selected repository.
- 🔗 **Link WBS ↔ Work info** — From a WBS task's "Related info", link related documents, links, and repositories to gather a task's full context in one place.
- 🗂️ **Meeting internal/external + 1:3 view** — Classify meetings as internal or external and browse them in a 1:3 master-detail layout (move with ↑/↓). Work logs are now recorded only on leaf WBS tasks (no children).
- ✨ **Visual hierarchy & consistency** — Unified sidebar, filter bar, and Markdown body width across screens for better readability.
- 🤖 **Stronger external automation & AI** — Use `atlas-cli` (shell) and MCP to query tasks, issues, and work info with targeted filters and update their status. A single `atlas-cli skill install` adds the Atlas skill to Claude Code so you can manage your data in natural language.

### Changed
- 🏷️ The screen label "Dev info" is now "Work info" (data and behavior unchanged).

### Notes
- Existing data migrates automatically on startup. All data stays local (SQLite + file folders) as before. No account, no remote server.
