# Atlas — Project Manager (ko-KR)

## 표시 이름
Atlas-Project Manager

## 짧은 설명 (요약)
여러 프로젝트의 일정·이슈·회의·변경 이력·자료를 한 곳에서 관리하는 로컬 우선 데스크톱 앱. 계정 없이, 모든 데이터는 내 PC에 저장됩니다.

## 설명 (본문)
Atlas는 한 사람이 여러 프로젝트를 한눈에 관리하기 위한 Windows 데스크톱 앱입니다. 일정(WBS·간트), 이슈, 회의록, 변경 이력, 업무 자료(문서·링크·깃 저장소), 리소스를 프로젝트별로 정리하고, 전 프로젝트를 통합 화면에서 모니터링합니다.

로컬 우선(local-first) 설계로, 모든 데이터는 내 PC의 SQLite 데이터베이스와 프로젝트별 파일 폴더에 저장됩니다. 계정 가입도, 원격 서버도 없습니다. 데이터 폴더 위치는 자유롭게 바꿀 수 있어, OneDrive 같은 동기화 폴더나 외장 드라이브를 가리키면 자동 백업·다기기 사용도 가능합니다.

회의록은 사람이 읽기 좋은 마크다운으로 자동 내보내져 Obsidian 같은 외부 도구와도 호환되고, 프로젝트 맵은 WBS·이슈·회의·변경·자료 사이의 관계를 그래프로 시각화합니다. 다크/라이트 테마와 12색 커스텀 테마, 한국어·영어 UI 전환을 지원합니다. 또한 atlas-cli·MCP 와 Claude Code 스킬을 통해 외부 도구·AI 에이전트로 데이터를 조회·갱신하는 자동화도 지원합니다.

AI 연동·자동화 설정 — Store 로 설치하면 자동화 명령 atlas-cli(셸)·atlas-mcp(MCP)가 함께 설치되어 터미널 어디서나 바로 쓸 수 있습니다. Claude Code 와 함께 쓰려면 터미널에서 atlas-cli skill install 을 한 번 실행하세요. 사용 가이드 스킬이 ~/.claude/skills/atlas 에 설치되어, 어느 프로젝트에서 Claude Code 를 켜든 "atlas-cli 로 …" 한마디로 작업 컨텍스트 수집·타깃 필터 조회·상태 갱신 워크플로우가 자동 적용됩니다(갱신은 --force). AI 에이전트가 MCP 도구로 직접 호출하게 하려면 claude mcp add --scope user atlas atlas-mcp 로 한 번 등록하면 됩니다. 모두 선택 사항이며, 앱 자체는 별도 설정 없이 바로 사용할 수 있습니다.

가벼운 단독 사용자용 도구를 찾는 분, 클라우드에 데이터를 올리고 싶지 않은 분, 프로젝트 전반을 한 화면에서 보고 싶은 분에게 적합합니다.

## 주요 기능 (불릿)
- 프로젝트 단위 관리 — 카드 목록 + 대시보드(개요·예산·인원·D-day·최근 활동)
- 내 업무(통합 할 일) — 전 프로젝트 미완 작업·미해결 이슈 + 개인 할 일을 한 화면에, 반복 할 일·한 줄 완료
- 프로젝트 회고 — 완료 프로젝트 비교(번업 S곡선·지연율·이슈 밀도·평균 해결 시간)
- WBS + 간트차트 — 계층 작업 트리, 마일스톤, 상태/중요도, 멀티 담당자, 관련 업무 정보·저장소 연결
- 이슈 관리 — 상태(열림/진행/해결/닫힘) × 우선순위, 표에서 인라인 변경
- 회의록 — 내부/외부 구분, 참석자·결정·논의·액션 아이템, 마크다운 자동 내보내기
- 변경 이력 — 영향도, 일자별 차트, 관련 문서·회의 링크
- 업무 정보 — 마크다운/파일/링크/깃 저장소 + 태그(저장소 커밋 그래프)
- 프로젝트 맵 — 관계 그래프 시각화(방사형/타임라인, 미니맵)
- 통합 모니터링 — 전 프로젝트 종합 차트 + 담당자×마감 히트맵
- 글로벌 검색 — Ctrl+K 명령 팔레트로 전 프로젝트 작업·이슈·회의·자료 즉시 검색
- 업무 일지 — 주간 한 일/계획/이슈 기록, 마크다운 내보내기
- 리소스 관리 — 인원·장비, WBS 담당자 자동완성
- 외부 자동화 · AI 연동 — atlas-cli·MCP 로 데이터 조회·갱신, Claude Code 스킬 1줄 설치(atlas-cli skill install)
- 자동 백업 — 전체 데이터를 지정 폴더로 주기적 zip(보관 개수 관리)
- 한국어·영어 UI 전환 + 다크/라이트 + 커스텀 색 테마
- 로컬 저장(SQLite + 파일 폴더), 계정·원격 서버 없음

## 이 버전의 새로운 기능 (What's new)

## 인증/심사 메모 — 전체 신뢰(runFullTrust) 정당성
Atlas는 일반 Win32 데스크톱 앱으로, 사용자가 지정한 로컬 폴더에 SQLite 데이터베이스와 프로젝트 파일을 직접 읽고 씁니다(예: 문서 폴더, 외장 드라이브, 동기화 폴더). 이 로컬 파일 접근을 위해 `runFullTrust` 기능이 필요합니다. 네트워크 원격 서버나 사용자 계정은 사용하지 않으며, 데이터는 사용자 기기에만 저장됩니다.
